Logic Explanation

The loot array works by validating each item the user inserts and then adds it to the array. As a bonus the user can also remove loot. After adding or removing loot, it calls the renderLoot function to update the values and loot list. It then displays it all on the screen. There are two loops used both in the renderLoot function with one updating the loot list and the other updating the values. The if statements make a decision in every function, however, it's mainly used for checking the party size and loot for validity. Outside of that it is checking if there are still items in the loot list.
